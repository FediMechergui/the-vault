# THE VAULT Android client

Flutter 3.50.0 / Dart 3.14. Run `flutter pub get`, `flutter analyze`, `flutter test`, then `flutter build apk --release` from this folder.

The same APK discovers each user's own server over mDNS and pins its certificate. Start the PC server on the same local network before opening the app. No fixed LAN address is compiled into release builds.

See the [project README](../README.md) for setup, release downloads, MATLAB requirements, signing and validation limits.
